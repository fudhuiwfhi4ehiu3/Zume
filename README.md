# Zume

Zume is an Android social app project.

## Project status

This repository is being prepared for the Android starter project. The Android source files and Firebase configuration have not yet been added, so an APK cannot be built from this repository yet.

## Next step

Add the contents of the `Zume_Android_Starter.zip` project folder to the repository root. Do not upload Firebase secrets or passwords. The Firebase `google-services.json` file should only be added after checking the project's Firebase setup and repository privacy.
