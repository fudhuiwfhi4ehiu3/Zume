# Zume — Android starter

Это исходный проект Android-приложения Zume: голубой экран регистрации и входа через Firebase Authentication.

## Что уже есть
- Переключение между регистрацией и входом.
- Создание аккаунта по электронной почте и паролю.
- Сохранение учётной записи в Firebase Authentication.
- Выход из аккаунта.
- Голубой интерфейс Zume.

## Что нужно настроить перед запуском
1. Установи Android Studio на компьютер.
2. Создай проект Firebase на https://console.firebase.google.com/ .
3. В настройках Firebase добавь Android-приложение с package name `com.zume.app`.
4. Скачай `google-services.json` и положи его в папку `app/` (рядом с `build.gradle.kts`).
5. В Firebase Console открой Authentication → Sign-in method и включи Email/Password.
6. Открой папку проекта в Android Studio и дождись Gradle Sync.
7. Запусти приложение на Android-эмуляторе или подключённом телефоне.

## Важно
Это стартовая версия, а не готовый APK. Для сборки APK нужен Android Studio/Android SDK и файл `google-services.json` от твоего Firebase-проекта. Не отправляй никому пароль или секретные ключи.

Пока реализована только регистрация/авторизация. Лента, загрузка фото/видео, личные сообщения, жалобы, блокировки, настройки приватности и модерация — следующие этапы разработки. Перед публикацией для других пользователей нужно добавить правила безопасности Firebase, защиту данных, жалобы/блокировки и понятные настройки приватности.
